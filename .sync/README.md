# sync

*Handbook: [`dplyr-alignment/setup/`](/handbook/dplyr-alignment/setup/README.md) owns how these clones are set up and used.*

Clones of the dplyr fork `krlmlr/dplyr` that the scripts under `tools/` read and write, untracked by git:
`dplyr-main` on the fork's default branch, and `dplyr-revdep` on `f-revdep-duckplyr`.
The commands that create them are on the handbook page above.
