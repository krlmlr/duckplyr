# Benchmarks

The TPC-H queries duckplyr is measured and tested with, the scripts that run and peel them, and where their results land.

**The per-script reference is [`tools/README.md`](/tools/README.md)'s**, under its TPC-H and touchstone headings,
including the three ways a query runs and the order the scripts are run in.

**The queries are part of the package and of its tests.**
The 22 TPC-H queries written with dplyr verbs live in `R/tpch.R` and `R/tpch2.R`, and `tests/testthat/test-tpch.R` runs them.
`tools/37-tpch-peel.R` and `tools/39-tpch-peel-oo.R` record each query's relational plan and write it back out
as `R/tpch_raw_*.R` and `R/tpch_raw_oo_*.R`, which `.Rbuildignore` keeps out of the built package;
both run at the end of every sync ([`dplyr-alignment/sync/`](/handbook/dplyr-alignment/sync/README.md)).

**Results are script output, not records.**
The benchmark scripts overwrite the `res-*.csv` files at the root, and `.Rbuildignore` keeps them out of the built package.
A measurement that a leaf leans on is recorded under `experiments/` instead ([`meta/local/`](/handbook/meta/local/README.md)).
`touchstone/script.R` is generated by `tools/70-touchstone-gen.R`, and no workflow runs it.
Reviving touchstone is planned, tracked in an issue.
